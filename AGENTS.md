# Orientações para editar este projeto no Codex

- Site estático em HTML/CSS/JS, sem framework e sem build.
- Preserve a identidade AC LEAL: azul #154E68, laranja #E58B32 e fundo claro.
- Centralize o cadastro em catalogo.js: foto coletiva em image, fotos individuais em products[].image, legendas de medidas em products[].size.
- Não estime dimensões, capacidades ou códigos comerciais. Onde faltar medida, use “Medidas sob consulta”.
- Os recortes individuais atuais são demonstrações. Substitua-os pelas fotos originais que o usuário inserir.
- Os filtros atuais usam pet, cartonagem e rotulos. IDs de conjuntos devem ser únicos.
- Mantenha o carrossel funcionando com um ou vários produtos e os caminhos relativos ao index.html.
- Use npm run validar após mudar o cadastro. Para prévia local: npm run dev.
- Confirme interações após alterar app.js. Não introduza dependências sem necessidade.
- Não publique automaticamente esta cópia local; ela é a entrega para edição manual. Publique apenas quando o usuário pedir.
